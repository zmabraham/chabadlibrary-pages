# Chabad Library Books

A collection of Hebrew texts from the Chabad Library (ספריית חב"ד ליובאוויטש).

## Contents

- **84 books** from the Chabad tradition
- **1,538 parts/volumes** (sefarim, chapters)
- **16,035 individual pages** (in progress)

## Structure

```
books/   - Book index files
parts/   - Volume and section indexes
pages/   - Individual page content (Hebrew)
```

## Source

Content scraped from: https://chabadlibrary.org/books/

## Status

Currently scraping: 725/16,035 pages (4%)

This is an ongoing project to archive the complete Chabad library.
